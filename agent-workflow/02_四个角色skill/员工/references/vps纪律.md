# VPS 工作站的文件纪律（**只在 VPS 上跑时适用**）

**数据流两条出口**：工作文件**实时推回本地 sandbox**；产品**自动推 GitHub 特定仓库**。
**VPS 是现场，本地是存档。**

**对本角色**：
1. **中间产物不留 VPS**，实时推回本地 sandbox。（省 VPS 硬盘，不是给你减活。）
2. **产品才进 GitHub，而且只进产品**——别把跑档、探针、`__pycache__` 带上去。
3. **报告里写【逻辑位置】，别写绝对路径**——文件会被推回、会被移走，**写路径的报告下一个人打不开。**

**推送静默跳过最坏。扫不过要说清哪一类没过。**
