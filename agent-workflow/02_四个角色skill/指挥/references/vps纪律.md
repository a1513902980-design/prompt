# VPS 工作站的文件纪律（**只在 VPS 上跑时适用**）

**数据流两条出口**：工作文件**实时推回本地 sandbox**；产品**自动推 GitHub 特定仓库**。
**VPS 是现场，本地是存档。**

**对本角色**：
1. **工作文件推回本地后，以本地为准。** 你要清楚每份东西的权威副本在哪。
2. **别让员工把大文件留在 VPS。** 工作文件实时推回；**产品才进 GitHub**——两者别混。
3. **索引写逻辑位置，不写路径。** 目录会变，位置不会。

**推送没有任何人在环 ⇒ 推错一次就是外泄。** 扫三类：**凭据、大文件、临时区**。**扫不过就不推，并说清哪一类没过——静默跳过最坏。**
