# VPS 工作站的文件纪律（**只在 VPS 上跑时适用**）

**数据流两条出口**：工作文件**实时推回本地 sandbox**；产品**自动推 GitHub 特定仓库**。
**VPS 是现场，本地是存档。**

**对本角色**：
1. **你读的文件可能已经不在 VPS 上了。** 找不到 ≠ 不存在——**先按逻辑位置去本地查，再报「缺失」。**
2. **判「过期」时要看时刻，不只看内容**（文件被推回的时间可能晚于你判断的时间）。
3. **报告里写逻辑位置**，别写物理路径——指挥按路径去找会找不到。

**你不会被要求管推送。** 但一次推送若把凭据或大文件带出去了，**那是你该报的机械问题**——它属于「不该在的地方有东西」。
