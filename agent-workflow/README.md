## 怎么读

1. **先读 `00_讨论汇总`** —— 四份角色 skill 是它的落地，不读它就看不懂那些约束为什么存在。
2. **再读四份角色 skill** —— 每份末尾都有「铁律总表」，那是可以直接执行的清单。
3. **`01_范本` 是写法参考**，不是内容参考。**要看的是它们怎么组织一份 skill**（什么时候用／什么时候别用／前置条件／铁律／边界），不是照抄里面的规则。

## 三条最容易漏掉的

| | |
|---|---|
| **原文 > 一切汇总** | 汇总只是索引。冲突时以原文为准。**静默覆盖禁止**——要改就加标记，原文保留 |
| **只读产物，不读关于产物的说法** | 监管读代码，不读报告。**替换比禁令强** |
| **能上索引上索引** | 能重新算出来的，只存"去哪儿查"；**算不出来的才存内容** |

## 一条前置条件（写在最后，但它是最底下的那块石）

> **「能上索引上索引」的前提，是那个东西有稳定地址。**
> **没有归属 ⇒ 地址不稳定 ⇒ 索引一定指空。**
> ⇒ **严格的储存纪律不是"能上索引"的补充说明，是它的前置条件。**
