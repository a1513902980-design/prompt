小东西 · 汇总

这里放我做过的、能打开、能跑、有文档的小东西。
大多是中小型站点规模的东西：静态站、脚本、网关、爬虫。

  • relay-egress · 转接出口

    本机只负责渲染，浏览器发出的每一个请求都从自己的 VPS 出去；目标站点看到的是 VPS 的 IP。

    和常见代理模式的区别不在功能，在结构：直连的代码路径不存在——上游不是回环地址就拒绝启动；隧道断了请求直接失败，源码里没有"回退直连"这条分支。不动系统代理、证书库、防火墙、驱动。

    Node 内置模块 · 零依赖 出口身份对照 进程出网审计 Windows / Linux / macOS

  • agent-workflow · 多会话工作站的实现原则

    把一次真实的多 agent 协作里学到的东西写成了十一条原则，每一条都带一个踩过的坑当出处，外加四个角色的 skill（对接／指挥／员工／监管）。

    重点不在"怎么用"，在"我们试过会漏，所以不许这么干"——比如：报"完成"不算完成，要先查它该写的东西在不在；只读产物、不读关于产物的说法。

    纯文本 · 无依赖 11 条原则 · 条条有出处 4 个角色 skill 两轮实测记录
